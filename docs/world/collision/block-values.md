# Owned World block values

The private owned entry in [the collision reader](../../../src/world/runtime/collision/blocks.c)
shares the complete existing block ID/metadata body with the held entry. The
caller owns the exact evaluated World before later source arguments and passes
its defining Chunk code sites plus a fresh required acquisition result. The
reader checks that current ownership before source fields, pairs its own native
World call, and leaves that exact World on every entered return.

The actual query retains the original bounds, provider validation, one get,
normal/Blank dispatch and block or Nibble read. It loads World.w after the get,
leases the actual Store/state pair and releases that same pair before publishing
the scalar. Existing box, state-shape and contribution callers keep their held
route. Public error layouts and Entity fields are unchanged.

## Loader results and source order

At the one reached get, the owned route uses the same
[acquisition kernel](../world-acquisition-execution.md). Its required result
receives the actual selected outcome and both possible pending continuations
before the local full acquisition frame is projected into collision diagnostics.
A completed failed selection supplies the protected inline loader view. The
selected child's acquisition status can differ from its parent's status; the
reader does not infer ownership by matching those numbers or searching old errors.

The actual source cause remains primary. Native ownership errors have their own
first-error result. If get succeeds but native completion refuses, the reader
stops before Chunk payload reads or scalar assignment and retains the pending
result. A native continuation cannot resume source execution or repeat the get.
Only a completed successful NONE selection is cleared before later scalar work.
The reader never pops its caller's scope or repairs a source field.

The source domain preserves the positive-Z distinction: z=32000000 passes the
World guard, while z=32000001 does not. That permitted far coordinate is not
claimed as tested by an outside-domain case. Existing
[collision reference notes](../../reference/collision-boxes.md) retain the
original client/server method and virtual-body evidence. No original JVM ran
for these native controls.

## Remaining caller work

The Arrow parent still needs result storage, typed source classification and
checked unwind/resume propagation. A refused descendant close needs the actual
callee's exact scope token and operation-specific continuation; a pending loader
alone cannot authorize popping another current World. The reader does not close
that parent boundary. Classless source errors also need their typed producer
classification rather than a guessed exception name.

Blank, the permitted far positive-Z boundary, foreign World/joint Store,
structural native completion refusal and general import/generation/population/
captured-provider descendant ownership remain unqualified here. Existing box,
ray, material/fluid, base, damage and full World-tick joins remain unfinished.
These controls establish this finite native scalar boundary; whole Arrow flight,
unrestricted single-player, original audiovisual equality and sustained FPS
remain open.
