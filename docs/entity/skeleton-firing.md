# Skeleton firing

The original client Skeleton attack is the complete 189-byte
`fr.a(Lsn;F)V` method. Its [retained source packet](../../tests/reference/entity/skeleton_fire/README.md)
contains 24 literal profiles in each of four fresh VMs: two ordinary VMs and
two passive debugger VMs. The 96 calls contain 60 normal returns and 36
exceptions. The four-VM ordinary-common domain agrees on 9,270 scalars; two
passive VMs supply 252 additional local-Arrow scalars for six profiles whose
locals ordinary observation cannot retrieve. Those ordinary fields stay null.

The range comparison returns for distance at least 10 or NaN before reading the
target. Below that range, target X and Z are read before cooldown. Any nonzero
cooldown skips construction but still reaches facing and the attacking flag;
a null target fails before that cooldown test.

When cooldown is zero, the method allocates an actual Arrow and invokes its
Living constructor. It raises the Arrow's Y by widened `1.4f` without rebuilding
the constructor's bounds. Target Y and the actual eye-height virtual supply the
vertical operand; the horizontal float square root supplies the lift. Arrow
targets inherit Entity's zero eye height.

The method captures the current World, draws the Skeleton's own Random float
and invokes bow sound. It then reloads the current World for publication, so a
sound callback can change the later receiver. A completed false publication
still reaches the second heading call. That heading uses the same Arrow's own
Random, speed `.6f` and spread `12f`. Only successful heading reaches cooldown
30, facing and the attacking flag. There is no remote-World guard in this body.

The native operation shares one entered body between Creature dispatch and its
closed component fixture. Creature dispatch independently retains its evaluated
target argument across callbacks. The body owns the actual Arrow allocation,
including failed constructor prefixes; an optional fixture output transfers
that occurrence. Ordinary dispatch releases the local once. World and Chunk
publication occurrences remain independent, and a later error does not roll back
their completed effects.

Optional observations copy actual arguments, Random transitions and child errors
without adding draws or persistent per-Mob storage. Constructor heading and
final heading retain distinct receipts. Their arguments use private 32-byte
buffers, valid under the corresponding error's existing `heading_entered` flag.
Public callers pass no observer. The public Arrow error stays 464 bytes, the
Mob call detail 464 bytes and the Entity NBT error 568 bytes. Arrow errors
contain values; concrete
WorldAccess callback errors borrow the actual producer graph. A null sound
interface receiver has a value-only null-reference failure and requires no
invented callback owner or retained producer slot.
