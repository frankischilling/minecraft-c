## Private native context

A frame-resident `mc_math_execution` borrows the explicit namespace until first
use, then owns one actual retained occurrence. Every reached use ensures that
same owner. Missing Math fails only at the reached operation. First failure,
current selection, native admission and cleanup causes are independent.
Retirement never reads an unused borrowed pointer, consumes only actual owned
rights and preserves them on refusal. No initialization or source work is replayed.

The material scanner and base tick remain single entered implementations.
Existing public paths pass no new context and keep their previous domain;
new Arrow water/lava callers require the private held entries with real execution
storage. Public stored-bx, watcher-byte, attacked, K and damage entries narrowly
admit genuine held READY client Arrow payloads. Arrow damage still returns false
after its inherited attacked flag, and void uses actual SN.ab/K rather than
Living damage. No diagnostic structure or per-Entity/Mob field is added.

The private base helper borrows the caller's actual Entity/Registry/World and
producer graph through returned diagnostics. It is not an opaque retained call.
A full Arrow owner additionally needs protected WorldAccess producer handoff,
stable loader diagnostics, dynamic evaluated World holds, complete SL source
composition and checked World dispatch/retirement. Those joins remain separate
work. No new original JVM, natural encounter, returned frame or FPS evidence
is supplied by this implementation alone.
