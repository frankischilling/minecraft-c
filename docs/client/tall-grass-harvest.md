# TallGrass destruction and Seeds

TallGrass destruction now reaches its original World color body through both
World rendering and QM particles. The same private RU body serves both callers.
It preserves the captured World operand, fresh manager reads, wrapped integer
hash and actual IA namespace. No generic white substitution or Leaf palette
is used for a nonzero metadata value.

## Tint and failure order

RU reads actual World metadata first. Only the returned integer equal to zero
returns white without climate or colorizer work. Other values compute the
original wrapped int sum `x*3129871 + z*6129781 + y`, widen it, then perform
the wrapped long hash. The resulting integer offsets select climate sampling
coordinates. This is distinct from crossed-plant geometry jitter.

The sampler is reached through one manager read. Temperature and rainfall
each perform a fresh manager read from that same captured World. IA active
use follows both doubles. Its real cold array, current nullable palette,
Java conversions and array access determine the result and reached failure.
QM only performs its ordered RGB stores after the color call returns.
Earlier constructor, sound, sampling and entropy effects remain visible when
a later source call fails; the retained native child owns its cleanup.

Two fresh guarded original VMs agree on 28 direct RU/QM calls in the
[tint packet](../../tests/reference/client/tall_grass_tint). Native replay
matches all 28 rows, including metadata0 bypass, IA versus JH selection,
signed coordinate hash overflow, raw RGB bits and nullable World/Dimension/
manager/palette prefixes. Actual DN controls append all 64 tinted particles
and retain the first constructed QM on a genuine IA failure. The existing
25 World-color rows and Leaf controls remain separate passing coverage.

## Harvest and source input

TallGrass inherits the base harvested-statistic and probabilistic drop body.
The source probability float precedes RU's `nextInt(8)` Seed decision. A zero
decision reads the current Seed Item static and continues through the real
Stack, protected spawn and Item publication path. Other decisions return no
drop. Shears has no TallGrass harvest override in this archive and does not
wear when destroying it; it does not produce a Block31 Stack.

The [controller packet](../../tests/reference/block/tall_grass_harvest) contains
74 calls from each of two unchanged guarded original VMs. Native replay matches
192 rows from 68 complete controller profiles, including Seed/no-Seed results,
World/Chunk aliases, statistics, both Random states, remote behavior, nullable
statistic/writer prefixes and held-Stack edge cases. The six direct NULL-Player
calls are supplemental original observations, not additional native coverage.

`client.tall_grass_harvest` is the separate Windows source-input SDK scene.
It authors a supported row of plants, punches first with an empty hand and
then surviving Shears, and advances through real input until an actual Seed
appears. It neither forces the drop nor repairs live World, RNG or input state.
A passive WorldAccess listener records each scenario Seed at publication,
including its exact protected-spawn bounds, Stack payload and World/Chunk
membership. Unrelated World Items cannot satisfy the scenario observations.

The initial qualified Windows scene passes 2,527 native checks. Eleven actual punches
produce one scenario Seed, one returned and retired BB draw, ordinary movement
and pickup, three complete held Seed frames and three Player Inventory frames.
The selected Seed and the ItemRenderer's cached Stack have the same identity.
Each held frame returns its flat icon9 geometry with 66 faces and 264 vertices;
the HUD and hotbar also return. All 704 destruction particles are published.
Shears remains at damage238, with unchanged used and broken statistics.

Independent typed NBT contains the actual Seed Item and exactly two Player
Inventory entries: one Seed in Slot0 and the unchanged Shears in Slot1.
Player health20 and score7 remain intact. The stopped 13-file save tree,
totaling 1,238,190 bytes, stays byte-identical through checked native retirement.
Both windows are absent after cleanup, and the observer is removed and freed.
The retained run reports unchanged selected inputs and imported resources;
all 1,939 selected input hashes were rechecked at that checkpoint.
Actual dropped, held and Inventory screenshots were also inspected.
Later runtime changes require a fresh selected-input qualification.

The current-source requalification passes 1,486 checks after three actual
punches: one with an empty hand and two with Shears. It publishes 192 particles
and one Seed, then returns three held and three Inventory frames. All 1,939
selected input hashes and 413 assets match the current sources. Independent
typed NBT and actual stopped/closed copies verify the 13-file, 1,225,756-byte
save tree through checked cleanup. The Shears remains at damage238.
