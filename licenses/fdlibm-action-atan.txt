The Netlib and actual JDK17 kernel operator/coefficient sequences are compared
independently of copyright headers and whitespace. Runtime qualification uses
the actual JDK17 Math.atan. This is not an earlier game-version substitution
or a host-libm shortcut. No OpenJDK source is included in this payload.

Adaptations rename the private entrypoint, replace pointer-aliasing word access
with memcpy/uint64_t extraction, encode the original coefficient words as exact
hexadecimal doubles, and add C17 types/assertions and formatting. Source branch
conditions, operation association, reductions and return formulas are retained.
The admitted FP profile requires strict binary64 nearest-even evaluation,
gradual underflow and no reassociation/FMA. Floating flags/errno are not claimed.
