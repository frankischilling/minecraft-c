This packet contains 78 original rows, interleaved as 39 direct KM calls and
39 separately prepared IZ wrappers. The existing native runtime's public entry
is `mc_item_use_on_block_begin`, which implements the genuine IZ wrapper.
Native comparison should select the 39 rows whose `inputs[0]` is 1. The other
39 original rows are supporting evidence. No direct native KM parity is implied,
and a test-only runtime flag or branch is unnecessary.

The original rows form an ordered shared-World cohort. A native harness must
state its conditioning policy explicitly. Simply filtering to 39 wrappers
changes the preceding World queue history. Passing the measured projection
under that policy qualifies those 39 finite projections, without establishing
identity of all residual World state. An alternative may run genuine wrappers
as additional declared conditioning calls, but their extra statistics or late
NULL-Player failures must stay separate from direct-KM parity. The implementer
and main integrator must choose and document that policy.
