# Redstone Item-use reference

Four fresh original VMs completed the two declared cohorts: 42 ItemStack wrappers
and 12 direct support predicates, with two ordinary captures of each. The sealed
packet passes outcome, exception-frame, stderr, input and entropy admission.
Native and loaded-client comparisons have separate evidence.

The two separate cohorts contain 42 genuine `IZ.a` ItemStack wrappers and 12
direct `SM.a` support predicates. Each cohort uses two fresh ordinary VMs and its
own genuine World. Within a cohort, all rows share that World, four Chunks and
the registered SM55 instance. The input rosters were frozen before the helper.
The original archive identity and complete selected class/Code metadata are in
`source-pins.json`; no original classes or assets belong in this packet.

`capture_reference.py` requires explicit `--execute`. It retains all four
process outcomes before interpreting them. The public projection changes only
repository ancestry and the explicit eight-file authored input closure. Compile
and process bounds, JVM flags, commands and helper bytes remain unchanged.

The helper authors Chunk arrays before each call: Blocks, metadata, BlockLight
and heights are zeroed; each Sky byte is `0x0f`; Chunk.i is zero and population
is true. It then writes the declared support, clicked and target inputs. It does
not clear or drain the Source lighting queue or Redstone Set, replace streams,
reseed Source RNGs, or write Source clocks or phases. Observer journals alone
reset per call. The queue and empty Set boundary state persist between rows.

The packet admits only the outcomes reached by the declared IE132/IZ40/SM11
branches. A callback refusal is the actual declared `IllegalStateException`
after the first cell publication. Null Stack fails at the authored helper call
boundary; null World and late null Player fail at their distinct Source frames.
Frame numbers are Java `StackTraceElement` line numbers, not bytecode PCs or
native traces. A normal false setter still consumes the Stack. A callback count
store leaves 99; a callback ID store changes the later statistic index to 332.
No arbitrary Throwable, setup failure, daemon stderr or extra stdout is admitted.

All raw stdout and stderr bytes are retained. LF selected, entropy and exception
projections must join the complete ordered raw stream. The only permitted stderr
is the exact four JDK SecurityManager warnings bound to the actual captured
helper directory. Two denial-guard records and ordinary completion are required.
Both VM outcomes in each cohort must agree on logical effects and exceptions;
constructor Random seeds are not compared across VMs.

Entropy observations cover the same owned World RNG before and after each call,
not default/global randomness. Set observations cover the complete observed
empty boundary topology and retained modification history. They do not qualify
populated trees, equal-hash entries, garbage collection or arbitrary Set states.
The observer assigns aliases by linear reference equality and strongly retains
the observed objects. This is an observer lifetime qualification, not proof of
unobserved object lifetime behavior. Same-namespace ownership is required.
