calls and 57 separately prepared Stack-wrapper calls. It uses the unchanged
Beta 1.7.3 client archive, SHA-256
`af1fa04b8006d3ef78c7e24f8de4aa56f439a74d7f314827529062d5bab6db4c`.
The original `la`/`rk`, `iz`, World, Chunk, Player and statistic owners are real

the explicitly declared callback failures and reentrant data changes.

Two fresh ordinary VMs and a third read-only JDI target returned byte-identical

The 21 reached method Code hashes match the pinned original archive. JDI makes

These are original observations, not 118 native comparisons.

## Direct bodies and Stack wrappers

Both direct overrides have descriptor `(Liz;Lgs;Lfd;IIII)Z`. Hoe `la.a` reads
the target and above Block first. Its actual predicate lets Dirt bypass the
face/above gates applied to Grass. It captures Farmland, emits its sound, then
reads the remote World flag. Remote success returns after sound. Local success
calls the notifying setter, ignores its Boolean result, then applies actual
Stack durability. Seeds `rk.a` returns false for a non-UP face before reading
World, Player or Stack. UP reads the target, live Farmland ID and actual
above-air predicate, calls the notifying setter using the Item's planting ID,
ignores its result, then decrements the signed Stack count.

The Stack wrapper `iz.a(Lgs;Lfd;IIII)Z` resolves the actual Item and invokes its
override at PC14. Only a true Item result reaches the Player used-statistic call
at PC34. Direct Item calls do not have that wrapper statistic. The genuine
App/Player/statistic context records both used and broken statistic deltas.
NULL Player can therefore return true from a direct body but fail in a true
wrapper after the mutation/count/durability effects. Those rows retain their
distinct source frames and outcomes.

Every real-Stack base input has separate, freshly prepared direct and wrapper
rows. The four NULL-Stack direct rows remain original-only; they cannot be
replayed by pretending an IZ-wrapper admission failure is LA147 or RK65. The
native comparison bridge selects the 57 wrapper rows. Its three authored Java
observer `IllegalStateException` rows may pair common effects with a native
status refusal; equality of Java exception classes is outside that comparison.
Native results and their checked inventory belong to the separate native run
receipt, not to this original packet.

## Inputs and observations

`profiles.tsv` and `declared-inputs.json` declare nineteen signed integer
columns: family, call route, Item ID, count, damage, damage selection, face,
X/Y/Z, target and above IDs, remote flag, nullable operands, reserved-zero
Farmland alias, sound callback mode, cell callback failure, planting ID and
declared Dirt ID. `packet.py` exposes the names in `COLUMNS` and admits the
closed matrix. Four large-Y sound controls and one captured-ID callback control
use explicit reflective changes to original final **instance** `bn` fields as
nonordinary data stress. They do not establish ordinary gameplay reachability
of such changes. No final static reference is replaced, and no Unsafe API is
used.

The matrix covers all five registered Hoe materials, Grass faces -1 through6,
Dirt's bottom/blocked bypass, false gates, remote Worlds, durability/count
boundaries and Java wrapping, large float-rounded sound coordinates, nullable
World/Player/Stack/sound operands, sound and notification failure prefixes,
late remote/captured-ID reads, Seeds faces, and real setter-false cases. In
particular, Seeds on Farmland at Y127 reaches the genuine failed Y128 setter
and still returns true/decrements. A planting-ID-zero case similarly reaches
a genuine unchanged-Air setter return. The captured-ID Hoe observer produces
another actual false setter return before durability. Actual final-static
accesses are observed in order; this is not executed NULL-final-static parity.

Each `FARMING` row retains exact signed Stack fields, target/above cells,
remote state, used/broken deltas, sound argument bits, selected observer
notifications and sparse differences over the four genuine Chunks' Block,
metadata, Sky light, Block light and height arrays. The read-only source journal
separately retains method arguments/results, actual field accesses/stores and
failure frames. `read_packet()` returns all118 records as dictionaries with
`profile`, `observed` and `events`; `profile.values[1] == 1` selects wrappers.
Input arguments are checked against the actual JDI entries. Sound bits are
checked against the actual World call, and the ignored-false-setter witnesses
require their actual observed false returns.

## Capture and retained failures

Run the optional original capture with a supplied archive, its original SDK
dependencies and a qualified JDK17.0.17, writing to a fresh ignored directory:

```powershell
python -B tests/reference/item/farming_use/capture_reference.py --output .local/farming-use-repeat
```

The controller freezes its six producer/input files before compilation and
retains every process result, stdout/stderr and before/after guard. It then
executes the complete matrix twice ordinarily and once under read-only JDI.
Public packet validation and native replay do not need Java or original assets.
Original classes, assets and Code bodies remain outside this package; the pins
contain metadata and hashes only.

The successful source cohort is privately retained as
`.local/farming-use-original-c`. Attempt-a failed compilation because ordinary
Java assignment to final instance `bn` was rejected. Attempt-b compiled and
entered its first ordinary call, then failed during observer restoration when
Java17 rejected assigning a static final reference, even to its earlier value.
Both frozen attempts and complete failure prefixes remain retained. The retry
uses explicit reflection only for the declared instance data and skips immutable
reference restoration. Twelve unexecuted final-static null/alias/rebind rows
were removed before the complete cohort. Neither failure is a parity pass, and
neither partial attempt supplied public observations.
