# Original expired Spawner tick

Two fresh ordinary JDK17 processes, one `-Xint` and one default, each invoked
unchanged client `CY.n_()` ten times over declared saved inputs. They loaded
real FD/MX Worlds and four saved normal Chunks, constructed and published a
real DC Player, and registered a passive observer through actual World.a(PM).
The observer recorded publication and particle callbacks without replacing
nearest-Player, factory, query, collision, spawn-predicate or publication leaves.

The first four cases observed unknown-name NULL return, an actual Arrow-to-Living
ClassCastException in CY, the six-Pig population cap, and four rejected Pig
candidates over Stone. Six independent bright Grass cases observed these
successful publications:

| Case | `-Xint` | Default |
|---|---:|---:|
| 4 | 2 | 2 |
| 5 | 0 | 2 |
| 6 | 1 | 1 |
| 7 | 1 | 0 |
| 8 | 1 | 0 |
| 9 | 3 | 0 |

Those differences are retained. No clocks, source fields, Maps or Random states
were repaired. `finite.json` preserves both complete structured outputs,
including raw float/double bits, accessible Random seeds/Gaussian cache,
actual IDs, callback order, positions, delays and differing success counts.
Rejected candidates are unavailable at this ordinary observer boundary; their
individual state is not invented. The sampled global Entity-counter deltas
are 0,1,1,4 for the first cases and4 for each Grass case.

Every observed success group consists of one actual entity-added callback,
twenty alternating smoke/flame pairs, then twenty `explode` callbacks from
Living.V. Callback-sampled delay stays unchanged within that group. Later
publications or the final sample observe the random delay reset. These are
callback and sampled-state observations, not an internal method/PC trace.
`native-invariants.h` exposes only common ID-delta/return/rotation/prefix and
per-success effect counts. Native tests with authored Random inputs remain
separate; this packet claims no complete original/native field parity or
captured-RNG injection into a native runtime.

The exact executed Java, cases, profiles and fixture manifest are published.
Portable capture/publisher/validator/control helpers and the C projection were
authored afterward. Archive Class/Code hashes and runtime-checked original
CodeSource/resource identities do not constitute live-Code or JDI evidence.
Two invalid preparations remain separately hash-bound: a compile-only observer
error, then a storage-preparation guard rejection before any Player/CY entry.
Neither contributes rows to the successful two-VM cohort.

All sixty authored input files and thirty directories stayed unchanged, as
did the nine-file native save used to prepare them. Each isolated copy changed
only its ten eight-byte session locks. Complete raw pipes, actual private
commands/receipts, classes, original JAR/dependencies/assets and World bytes
remain external. The publisher rechecks all physical inputs/products, commands,
archive identities, source/copy inventories and both complete raw streams twice
before writing. The offline guard reconstructs each selected stdout transport
and verifies its actual retained hash/count; this serialization is not a new VM.

this cohort or inherit its qualification. Rebuilding this publication requires
