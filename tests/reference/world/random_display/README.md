It prepares genuine Session, World, provider, cached normal/fallback Chunk and canonical Block objects. World queries remain original methods. Authored `pm` callbacks observe emissions and provide the explicitly listed mutation/failure inputs.

Run with matching JDK 17 tools and a fresh ignored directory:

```powershell
python tests/reference/world/random_display/capture_reference.py --client-jar b1.7.3.jar --output .local/world-ambience-original-display-20261030a
```

The capture admits exact JAR/class/Code and authored helper pins, then runs normally and with a read-only JDI observer. It checks actual class origins/resources, initialized original class closure, live Code identities, actual RNG arguments/returns/states, constructor clock evidence, call ordering and exceptions. All public text is LF. Captured answers, compiled helpers and original dumps remain ignored private artifacts; no source classes are recompiled or replaced.

## Observed source ordering

FD.q is 135 Code bytes. It constructs its local default Random at NEW4/invoke8 before reading World.r. Each of 1000 samples reloads World.r at six distinct sites, invokes nextInt16 at31/41/54/64/77/87 and forms triangular offsets with Java int wrapping. It invokes the real getter at100. Positive IDs select the live Block.m entry and invoke virtual b125 with the retained local Random. Counter increment128 follows successful children; return134 is genuine. There is no Block.n test or g/Q update.

The read-only observer counts actual draw invocation sites, acquiring-query sites and completed sample tails throughout each call. Detailed getter/Block argument observations cover the first sixteen samples. Complete RNG states are independently replayed from declared source inputs, including the callback replacement. Null World.r fails at31 after local construction; null selected entry at125 follows six completed draws. Provider-null control fails at FD.c(II)6 through FD.a(III)48 and FD.q100, after one completed sample/twelve draws.

All eleven display declarations have live Code pins. Direct calls record all reached original World query entries/returns and RNG returns. Source event payloads preserve raw IEEE bits and call order. The controls expose these distinctions:

- BS captures World.r once and keeps drawing from it after synchronous replacement; all six faces consume three floats even when no particle emits. Its lower-Y comparison is against zero, so Y64 air emits five particles while Y0 emits six.
- Water's nextInt64 precedes metadata. Lava's material and actual virtual-opacity gates precede nextInt100. Inactive variants and proven UU returns can accept an unused null argument Random.
- Portal still consumes the position/velocity draws later overwritten by its orientation branch. X-neighbor queries retain short-circuit order. Fire checks each enabled side independently; five faces emit ten particles. Leaves below provides a genuine false solid-support result followed by true Fire encouragement.
- Clearing the actual observer List during Torch's first particle leaves two original World particle calls and only one observer event. Callback exceptions retain the exact completed RNG/query/emission prefix.
- Integer-edge cases retain float-before-double rounding and wrapping neighbor arithmetic. Direct seeded argument observations remain separate from the sampler's actual default constructor entropy.

## Machine transport and scope

Private `observations.json` contains `sampler_records`, `display_records`, `sampler_rows`, `display_rows`, `sampler_event_rows`, `display_event_rows`, JDI summaries, coverage and limits. Full records preserve original failures and helper input identities. Events use one ordinal across particle and sound callbacks.

`DISPLAY_STATE` fields are case, Block ID, actual concrete class, scenario, outcome, argument seed48 or `-`, current World seed48 or `-`, original World seed48, particle count, sound count, total events. `SAMPLER_STATE` is case, scenario, outcome, current World seed, original World seed, g, Q and the three event counts.

`DISPLAY_PARTICLE` is case, global ordinal, actual name, six raw binary64 words (position then velocity/color). `DISPLAY_SOUND` is case, ordinal, name, three binary64 position words and two binary32 volume/pitch words. Sampler event lists use `SAMPLER_PARTICLE`/`SAMPLER_SOUND` prefixes; this changes only the transport label, with source payloads untouched.

This qualifies finite genuine cached-data controls. It does not qualify terrain generation, the Minecraft caller's GUI/device graph or concrete renderer Particle allocation. Authored callback failure adapters preserve their actual Java Throwable types; native IO errors can compare reached effects without claiming the same Throwable implementation. Independent default constructor entropy is observed and replayed separately, never rebound or inferred equal. Source-only controls must stay labelled when a native API cannot represent the corresponding genuine field input.
