# Ladder neighbor observations

This optional collector invokes the unchanged original client `dp.b(fd,IIII)V`
on the actual Ladder from `uu.m[65]`. The verified archive has SHA-256
`af1fa04b8006d3ef78c7e24f8de4aa56f439a74d7f314827529062d5bab6db4c`.
The archive and three reached method Code attributes are pinned before execution.

The fixture reuses the [metadata collector's](../metadata_set/README.md) real
World, provider and nine cached normal Chunks. Each independent call prepares
the actual block and nibble arrays before invocation. No replacement getter,
World subclass or instrumented game body supplies a result. Sixteen calls use
all metadata values with four stone walls; four more remove the matching wall
for orientations 2 through 5. World B is true for these calls, so the inherited
drop returns before quantity selection or Item construction. The Ladder method
still performs its metadata/support checks and notifying air setter.

Typed rows compare actual void return or exception, resulting block/metadata,
dirty store and unchanged World Random. Notification counts are retained as
separate original observations and are excluded from the comparison because
the two native and original fixtures have different prepared lighting planes.
This finite scope covers neither ordinary Item drops nor full mutation ownership.
Native controls cover those effects separately.

```powershell
python -B tests/reference/world/ladder_neighbor/capture_reference.py `
  --jar b1.7.3.jar --work-dir .local/ladder-original
```

`--native-stdout PATH` requires the native Ladder completion footer and compares
all twenty ordered typed rows. Altered keys, scalar types, operands, values,
ordering and missing rows are rejected. Inputs and compiled helper classes stay
fingerprinted across execution. Network, listeners, native library loads,
deletes and writes outside the private target directory are denied. Original
archives, classes and raw observations remain outside the repository.
