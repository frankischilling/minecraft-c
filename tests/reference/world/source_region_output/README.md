# Original source region output

This finite cohort calls the unchanged original region methods. `rj.d` obtains
the cached QJ; `qj.b` constructs Hz with an 8,096-byte buffer, the default zlib
DeflaterOutputStream with a 512-byte buffer, and DataOutputStream. An authored
unnamed Compound contains a ByteArray named Payload with 32, 12,000 or 20,000
deterministic xorshift32 bytes. Original `as.a(root,DataOutput)` writes it.
Explicit outer close commits through Hz to that same QJ and RandomAccessFile.
Original `rj.b` is called twice after each normal commit.

Cases cover fresh output, same-size rewrite, append growth, shrink, freed-run
reuse, negative coordinates, abandoned output and cache flush with an older
Hz still live. After flush, actual `rj.d` obtains a replacement QJ and file.
Closing the older Hz reaches its closed file and the original caught
IOException print at441. The marked cohort ends after that caught return.
Replacement commit and later growth are excluded. Final cache flush is cleanup
outside the marked cohort; abandoned and replacement streams stay strongly
held without source close.

Ordinary snapshots read fields through reflection, query the actual file
pointer and length, copy arrays and buffer bytes, and read output files.
Queries on closed files retain their IOException result separately from
source failures. Reflection opens only `java.io` and `java.util.zip`.
Observation can resolve or initialize support classes. Strong owner holds
exclude garbage-collection and cache-pressure timing claims.

The independent read-only JDI observer uses breakpoints, method-exit and
exception events, field and array reads, and bytecode hashes. It invokes no
target methods, allocates no target objects, changes no fields or locals,
and substitutes no clock. File-operation tracing runs only during actual QJ
commit, excluding constructor header loops and snapshot I/O. Cache close has
separate observations. Commit stores and file calls retain RAM offsets,
free sectors, growth, timestamps and owner identities.

The driver freezes helpers, scenarios, tools and archives before compilation.
It retains bounded complete process captures, initialization and library logs,
owner snapshots, buffer prefixes, region copies, class/Code identities and
unchanged-input checks. Each timestamp must fit its own process's real clock
interval. Typed payloads, allocation, growth and method order are compared
separately from compression byte identity. Exact 4,096-byte and 255/256-sector
boundaries remain unqualified.

These calls do not execute source Chunk, Entity, TileEntity or World saving,
caller Info accounting or gameplay reload. Native diagnostic441 remains
unfinished even though the captured original prints and returns.

Run with a full JDK17 and the verified supplied client archive. Each invocation
creates a new case directory and checks the archive SHA-256 before execution.

```text
python -B tests/reference/world/source_region_output/capture.py --source-root . --client-jar b1.7.3.jar --jdk-home <full-JDK17-home> --work-dir .local/source-region-output-reference
```

The default-OFF `MC_ENABLE_SOURCE_REGION_OUTPUT_REFERENCE_TESTS` option exposes
this capture through CTest. Recorded Windows and Linux profiles have separate
provenance, class/Code metadata and capture identities. Other environments
retain their own validation requirements.

The six normal branches check RAM and disk headers, free-sector masks, record
lengths, selector2, payload positions, every regenerated ByteArray byte, growth
and its second zero result. Only the common failed prefix of the older closed
file is compared. See [comparison scope](comparison-README.md).

`loader-Code.json` separately records static class and method-Code hashes for
22 client classes used by the Chunk integration. It contains no original method
bytes. Those static pins do not add original runtime coverage to this cohort.

Exploratory failures remain in private records. One helper compile failed
because a Method name shadowed the output Path. A later completed capture had
an incorrect abandon audit inventory from before negative-region creation.
Both were corrected before qualification and receive no passing credit.
