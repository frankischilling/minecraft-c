# Arrow constructors and heading

The unchanged client archive supplies the oracle for all three complete `sl`
constructors and `sl.a(DDDFF)V`. This packet contains 40 finite profiles in
each of two ordinary and two read-only JDI VMs: 160 entered calls, 148 normal
returns and 12 actual `NullPointerException` outcomes. Every VM returned from
37 rows and failed at the declared source instruction in rows 14, 15 and 38.
This qualifies component construction and heading. It does not qualify Arrow
ticks, collision/damage, firing call sites, C3, rendering, NBT or gameplay.

The method scopes are the whole original Code bodies: world constructor 59
bytes (return 58), position constructor 73 bytes (return 72), Living constructor
290 bytes (return 289), and heading 199 bytes (return 198). Each JDI VM retained
19 actual executing Code pins, 1,628 actual source events and 90 returned
Gaussian API calls. Every observed class resolves to the original JAR, SHA-256
`af1fa04b8006d3ef78c7e24f8de4aa56f439a74d7f314827529062d5bab6db4c`.
No decompiled/recompiled original class supplies behavior.
