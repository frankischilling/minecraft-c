`ra.a(ls,iz)` calls: wooden, stone, iron, diamond and golden Swords, then Bow.
Their actual Player icon queries return64,65,66,67,68,21. Each call emits six
batches with48/48/768/768/768/768 backing words. All19,008 words compare exactly.

The unchanged supplied JAR executes on a real hidden32x32 LWJGL Pbuffer.
The App is created by its complete genuine KQ constructor. Genuine KV, IK,
JI RenderEngine, SJ Font, FD World, LM Chunk, DC Player, RA/CV/IY, NW and IZ
constructors provide the reached graph. Real original atlas lookup/upload,
GL operations and NW.draw execute. No RAW/Unsafe allocation, game subclass,
substitute game body, source-state clearing or entropy rebinding is used.

The genuine Font constructor has already used the original singleton NW.
Its actual initial g footprint is recorded with18 nonzero stale coordinate/UV
words. It is retained unchanged. The Sword/Bow source overwrites active
coordinates/UV/normals, and the observed inactive color/reserved slots remain
zero. This finite known prior state permits full-word comparison with the
native CPU fixture's fresh NW. It does not qualify arbitrary stale backing
contents. The source's quad conversion remains its actual defaulttrue.

An ordinary original run checks six returns, closed NW batches and GL errors.
Read-only JDI observes the actual NW g[0:o] at all36 flush entries and pins the
live RA/NW Code against the original archive. The observed RA callsites are
335,423,554,687,824,959. Both processes have identical initial and final raw
backing words. The debugger neither invokes target methods nor writes target
state. It uses VM breakpoints and read-only field/frame/array access.

the selected owner/state/event records, and `provenance.json` binds source,
fixtures, toolchain, libraries and raw ignored artifacts. The public Java and
capture/audit sources existed and were pinned before the qualified capture.
