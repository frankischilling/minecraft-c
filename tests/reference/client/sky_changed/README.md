# RenderGlobal sky-change callback

`capture_reference.py` invokes unchanged original `n.e()V` and `dk.f()V` from
the hash-pinned client JAR on prepared real N/DK receivers. Eight profiles cover
the A/u gates, repeated identities, existing dirty-list entries, empty arrays
and NULL failure prefixes. Constructors are bypassed and declared; this is a
method-body comparison, not a completed World tick or rendered frame.

Each row records the profile, failure flag, dirty-list size, dirty-bit mask and
ordered queue-identity encoding. `finite.json` contains the exact observed rows.
The observer permits no network, listener or native-library activity and records
input hashes and process receipts.

`run_native.py` compares all eight rows from `mc_test_render_global_access`.
Additional native controls reach the real List-growth limit and check retained
callback receipts. The same DK is appended before its dirty store; allocation
failure retains earlier source effects. The fixture does not substitute general
range marking for the actual A-gated callback.
