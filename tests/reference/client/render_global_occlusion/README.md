# Closed query-poll prefixes

`finite.json` contains14 calls to the unchanged private `n.a(II)V` query-poll
method. The native runner compares all14 complete rows. These are closed CPU
returns or source exceptions before any ARB call; they do not qualify query
results, GPU visibility, the whole occlusion branch or public N submission.

The original observer prepares genuine Object-only N/DK receivers and actual
direct IntBuffers. It covers empty/reversed ranges before any array access,
null/empty/out-of-range arrays, null cells, idle entries with null buffers,
skipped waiting entries and a waiting entry's null-buffer failure at clear23.
An initial `[0,16)` range over15 entries proves the endpoint is not clamped.
Rows record the three source x/y flag pairs and buffer position/limit. The
game methods are untouched; no override, replacement query, forced return or
GL result is supplied. The guard reports zero network/native-link attempts.

The native probe prepares the corresponding actual N arena, DK objects and
Ge buffer, enters the real polling child under its borrowed N guard, and
checks source exception categories/PCs and retained frames. It also checks
unchanged counters, flags and buffer cursors, and no query/matrix rights.
One additional bytecode-derived whole-branch prefix control verifies that
the short initial range fails before the outer x=true stores. That control
is separate from the14 original polling observations. No source constructor
or complete public-submit execution is credited by this fixture.

`source-pins.json` binds the complete original N/DK class bytes and selected
Code. `capture_reference.py` verifies the JAR, JDK17, four SDK metadata JARs,
declared inputs and generated helper hashes before/after execution. It writes
the exact TSV inputs and bounded stdout/stderr receipts in a new private
output directory. Public `run_native.py` requires only the executable.
