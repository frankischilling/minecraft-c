The three existing Mob draw packages and their retained captures are not modified.

Seventeen authored operations run in five isolated profiles. The main profile executes actual WorldAccess dispatch and N's slime branch; normal and null-World constructors; first air/ground/expiry updates; DN expiry removal; single-particle first/reuse draws; the initial null-DN guard; and a genuine size-one Slime landing that emits eight PBs, followed by actual DN update/draw. Failed fields and the pending NW batch remain intact until final VM/context teardown.

Settings, IK→JI, CX, a separate Cow camera, DN and the full N constructor are genuine.
