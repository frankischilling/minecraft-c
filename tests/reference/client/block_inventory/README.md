# Block inventory method families

This packet records unchanged-original inventory color and shape methods on
all 96 registered Blocks in the verified Beta1.7.3 client archive, SHA256
`af1fa04b8006d3ef78c7e24f8de4aa56f439a74d7f314827529062d5bab6db4c`.
Two fresh guarded JDK17 VMs agree on all 13,194 rows. The helper compiles only
authored observation classes; the supplied game classes remain unchanged.

For each singleton, rows record its runtime class and declaring color/shape/
bounds-setter owners, render type, 23 signed metadata colors and shape results
from constructor bounds and declared non-cube bounds. All 57 type0 receivers
also record six face textures for every metadata value and for two late `bm`
field values with four metadata values. Raw colors and widened bound bits are
retained. The declaration rows and complete 73-class Block hierarchy bind
which methods are inherited. Only Leaves overrides the metadata color body;
Pressure plate, Piston base, Button, Trapdoor and Cake override item bounds.

`source-pins.json` includes complete class and method inventories for all
Block descendants and JH. `provenance.json` binds authored helper/input files,
JDK products, compiled observer identities and the repeated original outputs.
Both source guards report 96 Blocks, 57 type0 receivers and zero network or
native-library attempts. Inputs are hashed before and after the captures.

Native replay compares all 13,098 behavior rows exactly. The other 96 rows
are original declaring-class evidence. It separately retains the 17 original
Leaf color/shape rows and tests genuine RAW Block owners and invalid kinds.
Those native admission controls are not additional original observations.

The six corruption controls reject changed color bits, forged declaring
classes, incomplete intermediate-class inventories, changed render-type
partitions and altered LF transport. They validate packet integrity rather
than replacing a native comparison.

This packet covers Block virtual methods. It executes no original CV/BB
inventory geometry, GL, input, harvesting, pickup, GUI, audio or complete game
frame. Cactus/Stairs/Fence and other specialized geometry require their own
evidence. The separate native Sand scene qualifies its declared gameplay path.
