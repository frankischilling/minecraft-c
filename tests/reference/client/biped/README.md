# Original Biped CPU observations

This package contains authored source and fingerprints. It contains no original
classes, JARs, SDK archives, worlds or captured geometry answers.

`BipedObservation.java`, `protocol.py` and the complete class/Code
`source-pins.json` are byte-identical to the author package qualified on all three compilers.
The observer constructs unchanged supplied `fh(0)` objects and, in its notice
mode, the real independent `vu(null)` graph. It checks defaults,
part/vertex/quad values, position/UV aliases, simultaneous owners, Vec3 pool
isolation and unchanged DefaultRandom uniquifier for the standalone model. It
drops Java references without claiming deterministic Java destruction.

`compare.py` requires explicit matching JDK17 java/javac, the supplied client JAR
and the pinned LWJGL2.9.0/JInput/JUtils Java archives. It validates the complete
class/Code metadata, real JVM class-load origins from the supplied game/SDK
archives, the helper-only class directory and the directly executed native
probe's bytes. Four fresh CPU profiles yield 838 ordered original rows and are
compared only after complete successful original/native process capture. The
helper, tools, libraries, native executable and source fingerprints are checked
again after the run. Every failed process/stream/timeout remains a failure even
if its stdout looks valid. The existing mature public Notice capture/class-file
owners are reused, not copied or weakened.

The original profile does not activate ge/nw, Display, GL, input, Sys or OpenAL.
No native .dll/.so is required. Windows and Linux use the same unchanged Java
observer; this is separate from the existing Notice callback reference driver's
Windows-only policy. `provenance.json` binds the actual native/reference/control
and shared-helper source inputs. It does not prove that an arbitrary executable
was built from them: a coherent build source/product qualification supplies
that separate guarantee. CTest passes the actual selected target executable.

Default `run_native.py` uses authored native output and validates all seven
contract/record/FP profiles without a private JAR. Public driver controls use
fresh native stdout, malformed process metadata, sanitizer diagnostics and
ordered-record mutations; no captured-answer fixtures are needed. Both normal
and optimized Python execute explicit conditions. The existing public capture
fault controls remain enabled independently.

The public wiring/wrapper passes the combined 389 Windows/381 Clang/381 GCC
case matrix, including 128 normal/optimized driver controls and 838 fresh
original rows per compiler. Earlier selected source qualification retains its
separate scope. App.x, general-float models, animation and drawing remain unfinished.
