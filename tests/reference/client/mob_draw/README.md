# Original Sheep drawing

This package executes the unchanged Beta 1.7.3 client Sheep renderer on a real LWJGL2 Display. It observes the actual TH/GV/XY renderer and MW/EA models, first list compilation, reuse, and the genuine Settings.j=true BW shadow. It supplies authored inputs and observers, not original implementations, assets, captured answers or replacement virtual methods.

Run under Linux, including WSL, with matching JDK17 tools, Xvfb/xauth and the user-imported SDK libraries:

```sh
python3 tests/reference/client/mob_draw/capture_reference.py \
  --client-jar b1.7.3.jar \
  --libraries /mnt/c/Users/admin/AppData/Roaming/.minecraft/libraries \
  --natives-archive .local/lighting-linux-sdk-20261029/lwjgl-platform-2.9.0-natives-linux.jar \
  --output .local/mob-draw-original-20261031a
```

The output must be a fresh ignored directory. The driver creates separate Xvfb/software-GL contexts for ordinary and read-only JDI execution; it does not open a Windows window. Device/vendor/version remain observed values. SDK/native/JDK/Display tools, all public inputs, reused authored helpers and compiled helper classes are pinned before and after. Every public text input is LF. The selected JAR, whole classes, all selected method Code and actual runtime origins are verified. No source class is recompiled or shadowed by an authored class.
