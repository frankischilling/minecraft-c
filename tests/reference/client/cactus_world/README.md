calls on the unchanged Beta 1.7.3 client archive, SHA256
`af1fa04b8006d3ef78c7e24f8de4aa56f439a74d7f314827529062d5bab6db4c`.

produce byte-identical complete stdout. The JDI cohort records 2,133 events:
669 actual EW query entries with exact arguments/results, 148 NW additive calls
and their 444 ordered field stores, five source exceptions, and ten live method

The helper constructs real saved-World FD/MX owners, loads four genuine LM
Chunks, constructs EW and each CV normally, and uses registered Cactus
`uu.m[81] instanceof or` and the original `nw.a` constructor singleton. One
real begin and translation setter precede all cases. Its actual 2,097,152-word
backing remains unchanged in identity and capacity. There is no draw, batch
repair, raw owner allocation, fake World/cache adapter, source method replacement
or GL context. Reflection authors declared data fields and reads retained state;
JDI never writes or invokes target state.

Profiles cover direct RGB and the color/anaglyph wrapper, empty/occluded/mixed
neighbors, render-all, retained CV.m, rotations/flip/texture overrides, partial
and outside bounds, each bound separately NaN, signed-zero lower bounds, live

wrapper mode, return, exception kind, before/after NW word indices, actual
