# Wolf, Zombie, and Skeleton drawing

This finite protocol observes fourteen calls through the unchanged original
`TH.a(SN,F)` renderer. It covers first compilation and reuse, a second Skeleton
sharing the real class Bow Stack, sitting/angry/tame/wet Wolf operands, the
Bow's full-3D predicate, a separate RA/App/Engine, and a mixed revisit. The
native fixture uses real constructors, World data, Registry, Math, Display,
models, texture lookups, and retained draw owners. No observation is an input
to native execution.

The Java files and the two TSV files are byte-identical copies of the authored
v2 inputs used for the historical ordinary/read-only-JDI capture. This public
package was created later. `provenance.json` records that chronology and the
separate current byte bindings; it does not claim these public paths existed
at capture start. `source-pins.json` contains static archive/class/Code hashes,
not captured state, geometry, or pixel answers. No JAR, compiled helper, or
large observation packet is distributed here.

## Limits

Only prepared final modelview/projection matrices have the finite four-float-ULP
and opposite signed-zero numeric allowance. Geometry, known normals, model
arithmetic, counters, and query operands remain exact. An actually unknown
native current attribute is preserved as `known=false`/`null`; the Original
legacy raw value is retained without equality credit. No attribute is reset
to make an observation pass.

Native raster checks establish authored visibility only. Original pixel
equality, complete live native GL invocation order, per-part device matrices,
whole-frame equivalence, raw Entity fieldset equality, displaced LC constructor
allocation trace parity, deep JDK buffers, complete texture-cache graphs, and
native Block dynamic-class observations are outside this finite comparison.
The parent RA/held/lookup guard ownership and native retirement controls are
distinct from the successful Original draw outcomes. No failure prefix is
repaired or replayed during retirement.
