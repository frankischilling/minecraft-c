# Original MovingPiston direct draw

This packet records 27 direct calls to the unchanged client HY.a(UK,DDDF)V,
after zero, one or two declared direct UK.n_ ticks. Four fresh JDK17 processes
ran: ordinary and passive-JDI captures in both interpreter and default modes.
Each process used a genuine hidden32×32 LWJGL Pbuffer, original JI/IK texture
loading and the original terrain resource. It does not establish a visible
window, pixels, ordinary World ticking, placement gameplay or native parity.

The cases cover six directions for early moving heads, carried stone and
retracting head/base pairs, plus later progress, completed/NaN/missing-Block
culls, negative and upper-clamped interpolation, sticky texture and AO paths.
Each case loads four authored saved Chunks through genuine FD/MX/RH/OK/LM,
constructs UK, publishes it through World.a, and constructs an unpublished Pig
viewer for actual LL frame preparation. The app/LL/HY/JI/NW graph is shared.
No UK field, World Map/List, Random, buffer or geometry is repaired.

All four parsed target streams agreed. Each passive observer recorded 27 HY
entries/returns, 24 active NW batches, 1,914 selected source-call events and
25 live method Code checks. Archive pins cover 35 classes, 853 declared
methods and 837 Code bodies. Archive hashes alone are not live-Code evidence.
Both full journals agreed after replacing numeric debugger object IDs with
class-specific encounter-order labels. Raw private streams and IDs remain
hash-bound in provenance. Constructor/World entropy is not compared.

The source counts are observed at NW.a entry with actual HY callerPC357.
Each vertex occupies eight raw 32-bit words; default NW quad conversion is
retained. Native comparison data contains only the actual active prefix.
The separate ordinary 768-word snapshots include stale suffixes and must
not be used to infer active vertex counts. Incidental texture IDs are omitted
from the native retained-state projection.

`packet.read_packet()` returns `declaration`, `cases` and comparison-only
`expected` rows (`index`, `vertices`, `word_count`, `words`, `retained_state`).
Execution inputs are cases.json, profiles.tsv and write_world.py; expected
observations must never become execution inputs. The standalone World
authorer was packaged after capture. It requires all 135 complete uncompressed
NBT payload byte hashes to match the original inputs and reports compressed
wire differences separately. Windows zlib-ng reproduced all 81 original files;
upstream zlib on Linux emitted different region compression with identical
complete NBT payloads. No compressed-byte identity is claimed for that case.
It does not launch Java or a native client.

The three Java helpers are the exact executed bytes. For a new original
capture, compile them against an independently verified original client JAR
and the four pinned LWJGL/JInput dependency archives, then use the argument
contracts in the helpers. PistonDrawObservation takes JAR, owned authored
saves, profiles.tsv, pinned native directory and owned work directory.
PistonDrawJdi takes output, JDK, mode, natives, target classpath, JAR, saves,
profiles and work. Provenance gives role-projected options; exact historical
private commands remain in hash-bound receipts. Each process requires a fresh
authored saves root and existing owned work/home, work/tmp and work/texturepacks
directories. Point java.io.tmpdir at work/tmp and clear JAVA_TOOL_OPTIONS,
_JAVA_OPTIONS and JDK_JAVA_OPTIONS before launch. No raw original archive,
Class/Code bytes, assets, World/NBT files or private streams are included.

The first preparation stopped during ImageIO pack-image loading because its
temporary cache was outside that guard's policy. It is retained separately
and excluded from the successful cohort. The final preparation owns its
ImageIO temporary directory and permits only its cache-file deletions.
The earlier byte-only portable authorer failures remain retained. The 68 packet controls are synthetic corruption tests, not further original runs.
